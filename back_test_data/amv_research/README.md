# 活跃市值反推：第一轮结果

本轮得到一个可独立计算的收盘值替代公式，尚未识别或证明指南针原始公式。

验证期选出的候选是：**各行业换手量代理值做 20 日指数平滑，再按当天行业指数重新估值后求和**。

## 公式

对 90 个行业，令：

- `M[i,t] = float_mv / 100000000`：行业流通市值，单位亿元；
- `h[i,t] = turnover_rate / 100`：行业换手率，小数；
- `P[i,t] = close`：行业指数收盘点位；
- `q[i,t] = M[i,t] * h[i,t] / P[i,t]`：换手量代理值，**不是真实股票数量**。

递推计算：

```text
alpha = 2 / 21
Q[i,0] = q[i,0]
Q[i,t] = alpha * q[i,t] + (1-alpha) * Q[i,t-1]

AMV_hat[t] = 7.695442042177039 * sum(P[i,t] * Q[i,t])
```

等价于 `7.695442 × Σ close × EMA20(float_mv/1e8 × turnover_rate/100 ÷ close)`。
这里 EMA20 的参数是 `span=20, adjust=False`，并非 20 日简单平均。
倍数是训练期标定系数，不是指南针已披露的常数，也不是可直接解释的筹码比例。
输出沿用目标 AMV 的数值尺度，不确认原始 AMV 单位为亿元。

输入第一天固定为 2024-09-10；未来续算应保留这天起的历史或保存每行业 EMA 状态。
所有输入来自独立 THS 板块数据；公式没有读取原 AMV 的成交量、成交额或前一日值。
只反推收盘序列，没有把估算收盘值伪造成开高低收行情。

## 数据和研究设计

- 原始目标：SQLite 中 `0AMV` 的 close，仅取与板块数据共有的 486 个交易日；`data/core_index/0AMV-2013-2026.csv` 保留为备份。
- 行业数据：90 个行业，43,740 行；完整日期×行业网格，无空值、重复键或非法数值。
- 2024-09-10～2024-12-09 用于初始化和平滑预热，不计入训练指标。
- 训练：2024-12-10～2025-06-30，共 133 日，拟合标定系数及部分模型参数。
- 验证：2025-07-01～2025-12-31，共 126 日，按对数均方误差选择模型。
- 测试：2026-01-05～2026-09-11，共 169 日，只用于报告样本外表现。

比较 106 个候选，分为流通市值、成交额、成交额 EMA、换手市值 EMA、按现价重估的 EMA、滚动换手饱和模型、活跃筹码衰减递推、换手弹性模型 8 类。
参数未按测试期成绩选择，也没有为每个行业独立拟合权重。
已经查看的测试期不能在后续调参后继续称为全新盲测；下一轮应使用时间滚动验证或新增留出样本。

## 主要结果

| 指标 | 训练期 | 验证期 | 测试期 |
|---|---:|---:|---:|
| 数值平均绝对相对误差 MAPE | 4.89% | 2.05% | 3.39% |
| 数值 R² | 0.654 | 0.974 | 0.880 |
| 日涨跌幅相关系数 | 0.980 | 0.957 | 0.970 |
| 日涨跌幅平均绝对误差 | 0.417 个百分点 | 0.371 个百分点 | 0.416 个百分点 |
| 日涨跌方向一致率 | 95.49% | 96.03% | 95.86% |

测试期最大单日数值相对误差为 8.01%。2026-09-11 原值 172364.30，估算值 162709.55，偏低 5.60%。
训练误差高于验证误差，说明误差具有阶段性，不能只报告最好的一段。
数值 3.39% 的误差和涨跌幅 0.416 个百分点的误差是不同指标，不能混淆。

## 与现有策略信号的一致性

按当前默认规则：单日涨幅 >4% 或连续两日正涨幅之和 >4%，且站上 MA10 启动；单日涨幅 <-2.3% 或跌破 MA10 退出。全样本连续生成状态，再分别统计各期间，不在测试起点重新初始化状态。

- 测试期多空状态一致率 **85.80%**。
- 原指标有 5 次启动，候选公式有 4 次，只有 **3 次同日启动**，启动召回率 60%。
- 原指标有 5 次退出，候选公式有 4 次，只有 **2 次同日退出**。
- 验证期没有新启动信号；其 99.21% 状态一致率不能用于宣称启动识别能力。

因此现阶段不能认为可以无差别替换原指标的 4%、-2.3% 等交易阈值。本轮是指标复现研究，不是收益回测，没有证明可盈利。

## 解释与尚未识别的部分

这个候选支持一种可检验的解释：AMV 的变化与“近期参与交易的数量经过平滑，再按现价估值”高度相关。
当新成交减少时，平滑的量代理值会下降；即使部分行业价格上涨，全市场合计仍可能不涨。
这为科技抱团与 AMV 背离提供一种机制解释，**不构成主力是否进场的证据**，也没有对用户所指的某段具体行情做因果识别。

仍有以下差异来源：

1. 原指标的股票范围、自由流通股定义、筹码活跃衰减参数及除权处理未知。
2. 当前行业成分 5578 条、5558 个唯一代码，包含北交所成分及跨行业重复；历史成分日期全空，无法据此精确消除历史重复或调整市场范围。
3. 行业指数价格不是个股价格，板块汇总会损失个股换手和筹码分布信息。
4. 当前下载的历史数据可能经过供应商修订，缺乏各交易日当时的数据快照。
5. 只有近两年有效重合样本；尚未验证更长熊市及其他市场制度阶段。

资金流数据只用于探索性相关诊断，未纳入最终公式。THS 12 个全零日、2024-09-30 算术异常和缺失日均没有补零后用于相关计算。
`diagnostic_correlations.csv` 使用全样本可用日，属于描述性分析，不是模型验证成绩。
