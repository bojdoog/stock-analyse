异常类型：
- HTTP 504，upstream_pool_exhausted：上游数据暂不可用。
- HTTPS 读取超时：有 15/45 秒超时提示及没有秒数的读取超时。

- HTTP 503 Service Unavailable、HTTP 502 Bad Gateway。
- 本次没有观察到权限不足错误。

真正卡住的位置：
对概念资金流进程 py-spy 抓栈确认停在 ssl.read -> urllib3.read_chunked -> requests.content -> session.post。
也就是说在读取转发服务的 HTTP 分块响应，不是数据库入库。
原本 timeout=(15,45) 不是整个请求的总时限；持续零星返回响应可能使等待延长。
该请求后来自行返回，没有强制终止概念资金流进程。

本次修复：
共享 tushare_client.py 加入整个请求 90 秒总时限（含响应体解析），超时后报错并更换 Session。
使用后台 daemon 请求线程隔离阻塞读取，因此即使底层连接未及时结束，也不会阻止 fetch 主流程退出。
已添加模拟响应体卡住的测试。
