# 申万行业日线与活跃市值

2026-10-17 起停止申万数据拉取：统一入口不再拉取申万行业日线，也不再自动生成申万反推指标。申万日线和成分股拉取脚本已删除。

既有 CSV、SQLite、MySQL 数据及拉取报告保留。`build_sw_amv.py` 仅作为基于已有数据的手动计算工具保留，不发起申万行情请求。

CSV 按交易日保存到 `data/sw_index/YYYYMMDD.csv`；有效记录同时存入 SQLite、MySQL。数据库不可用时沿用项目的待同步队列。

新指标为 `AMV_SW_EMA20`，显示名称“活跃市值(申万反推EMA20)”，不替换指南针或 THS 版本，也不增加买入排名。

公式：`scale × Σ[行业收盘点位 × EMA20(成交额元 / 1e8 / 行业收盘点位)]`。不使用资金净流入或成分股数据。标定系数以 2024-12-10 至 2025-06-30 的原指标拟合后固定，日常续算不使用原指标。模型保存于 `data/sw_metadata/amv_model.json`；仅显式执行 `build_sw_amv.py --refit` 才重新标定。

缺失行业日沿用该行业上一有效贡献，不补零、不使用未来值。EMA 在该行业缺失日不更新。报告记录缺失贡献数量和拟合偏差。

输出 `data/core_index/candidate_amv_sw_close.csv` 并导入指标日线表。收盘为估算值，开盘取前收，高低取两者极值，是合成日 K，不代表真实盘中高低。成交量、成交额为当日可用申万行业数据之和，单位分别为股、元。拟合好坏不等同于策略收益提升，训练期内的回测也不是样本外检验。
