# 活跃市值多空区间轮动策略

## 1. 策略概述

本策略基于"活跃市值（0AMV）"识别市场的牛熊情绪区间：

- **多头区间**：活跃市值确认启动，说明市场进入赚钱效应阶段，此时跟随当天最强的板块 ETF。
- **空头区间**：活跃市值退潮，市场进入亏钱阶段，此时买入银行 ETF 避险（基于"国家队会护盘、银行抗跌"的经验假设）。

本质是一个 **情绪择时 + 板块动量 + 防御切换** 的轮动策略。

---

## 2. 核心思想

1. 用"活跃市值"代替指数，判断市场整体情绪。
2. 只在多头区间持有进攻型资产（板块 ETF）。
3. 在空头区间切换到防御型资产（银行 ETF）。
4. 通过板块动量，抓住每一段热点行情的最强品种。

## 4. 区间识别算法

区间识别代码在 `src/pages/ActiveMarket/utils/backtest.ts` 的 `identifyZones` 函数中。

### 4.1 多头区间启动条件

遍历活跃市值数据，计算每日涨跌幅：

```
change = (close - prev_close) / prev_close * 100
```

满足以下任一条件即视为多头启动：

1. **单日暴涨**：`change > 4%`
2. **两日和突破**：当日涨跌幅 > 0 且前一日涨跌幅 > 0，两日累计 `> 4%`

启动后进入多头区间。

### 4.2 多头区间结束条件

进入多头区间后，每日检查：

1. **单日暴跌**：`change < -2.3%`
2. **跌破 MA10**：收盘价跌破 10 日移动平均线

满足任一条件即视为多头区间结束，进入空头区间。

### 4.3 空头区间

多头区间以外的区域即为空头区间。

## 5. 交易规则

### 5.1 多头区间

- **买入时机**：多头区间启动日当天收盘前。
- **选股规则**：在所有板块 ETF 中，计算每只 ETF 启动日相对前一天的涨幅，取涨幅前 5 名。
- **仓位分配**：
  - 第 1 名：30%
  - 第 2 名：30%
  - 第 3 名：20%
  - 第 4 名：10%
  - 第 5 名：10%
- **卖出时机**：该多头区间结束日当天收盘前卖出。

### 5.2 空头区间

- **买入时机**：空头区间开始当天收盘前。
- **标的**：银行 ETF（`512800_银行ETF.csv`，对应名称"银行 ETF"）。
- **卖出时机**：该空头区间结束日当天收盘前卖出。
- **特殊规则**：**从 2023 年起才开始买入银行 ETF**，2023 年之前的空头区间空仓不操作。

## 6. 回测规则

回测代码在 `src/pages/ActiveMarket/utils/backtest.ts` 的 `runBacktest` 函数中。

### 6.1 基本设定

- **回测起始年份**：2019 年
- **初始净值**：1.0
- **跨年收益归属**：跨年区间的收益全部计入区间开始的那一年。

### 6.2 收益计算

每只 ETF 的区间收益：

```
holding_return = end_close / start_close - 1
```

组合区间收益为各持仓按权重加权求和。

### 6.3 年度净值

每个交易按开始年份归类，年初净值继承上一年末净值，年内各波段按复利滚动：

```
nav_after_trade = nav_before_trade * (1 + trade_return)
```

## 10. 可调整参数

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| 多头启动单日阈值 | 4% | 单日涨幅超过此值启动多头 |
| 两日和启动阈值 | 4% | 连续两日累计涨幅超过此值启动多头 |
| 多头结束单日阈值 | -2.3% | 单日跌幅超过此值结束多头 |
| MA10 跌破开关 | 开启 | 收盘价跌破 MA10 也结束多头 |
| 银行 ETF 防御起始年 | 2024 | 从该年起空头区间才买银行 |
| 回测起始年 | 2019 | 回测数据从该年开始 |
| 多头持仓数量 | 动态 | 可自定义买入涨幅前 N 的 ETF，默认前 5 |
| 仓位权重 | 30/30/20/10/10 | 前 N 名 ETF 的资金分配比例（单位为百分比） |

## 11. 已知限制与注意事项

1. **后视镜偏差**：回测中当天收盘后才能确定涨幅前 5 的 ETF，实盘需要次日开盘执行。
2. **ETF 上市时间**：部分 ETF 在回测早期尚未上市，代码中已自动过滤无数据标的。
3. **滑点未扣除**：当前回测未考虑交易滑点、手续费、冲击成本。
4. **银行护盘假设**："空头买银行"基于历史经验，极端行情下可能失效。
5. **参数未优化**：当前阈值（4%、-2.3%）是经验值，未经过严格的参数优化。
